# AGENTS.md

## Commands

```bash
npm install          # install dependencies
npm run serve        # start vite dev server
npm run build        # production build to dist/
npm run build-preview  # preview the production build locally
npm run deploy       # deploy dist/ to GitHub Pages via gh-pages
npm run tlwind        # compile Tailwind CSS (one-shot)
npm run tlwind-watch  # compile Tailwind CSS in watch mode
```

There are no tests, linting, or typechecking scripts. `npm test` is a placeholder that exits 1.

## Architecture

- **Entry point**: `index.html` loads `js/main.js` as an ES module. All DOM event wiring happens there.
- **`js/canvas.js`** — initializes the Fabric.js canvas and loads `portfolio.json` via `loadFromJSON`. Also handles responsive resize.
- **`js/object.js`** — all object manipulation: generate shapes, import images, delete, copy/paste, layer ordering, color changes.
- **`js/context-menu.js`** — shows/hides the right-click context menu.
- **`js/canvas-export.js`** — save canvas to JSON, export as JPEG/PNG.
- **`portfolio.json`** — the actual portfolio content as a Fabric.js canvas JSON export. This is the data file loaded on startup; it is edited through the canvas UI (Ctrl+S to save).

## Gotchas

- **Tailwind CSS is not processed by Vite.** `css/styles.css` is generated by the Tailwind CLI (`npm run tlwind`). After changing `css/input.css`, you must run `npm run tlwind` or `npm run tlwind-watch` — Vite will not do it for you.
- **`vite.config.js` sets `base: "/canvas-portfolio/"`** — this must match the GitHub repository name for GitHub Pages asset paths to resolve correctly. If the repo is renamed, update this.
- **Deploy pushes to the `gh-pages` branch** — `npm run deploy` runs `gh-pages -d dist`, which force-pushes the `dist/` directory to the `gh-pages` branch. The `dist/` directory is gitignored.
- **Tailwind CSS v4** — uses `@import "tailwindcss"` in `css/input.css` and the `@tailwindcss/cli` package. There is no `tailwind.config.js`.
- **Fabric.js v7** — uses modular imports from the `"fabric"` package (e.g., `import { Canvas, Rect, Circle } from "fabric"`).
- **JSON import assertion** — `js/canvas.js` uses `assert { type: "json" }` (older import assertion syntax). Don't "fix" it to `with` unless the toolchain is updated to match.
